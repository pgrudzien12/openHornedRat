## `RT_BITMAP` — `BITMAP.DLL`

All 717 are **uncompressed 8 bpp DIBs** (`BITMAPINFOHEADER`, 40 B) with a **full 256-entry
palette** (715 × `biClrUsed = 0`, 2 × `256`), rows bottom-up, padded to 4 bytes. So:
resource size = 40 + 1024 + `ceil4(w) × h` (checked on all 717). Resource names are the
names used by the glue scripts (`setbitmap:Caravan` → `CARAVAN`); animations are numbered
frames `NAME1..N` or `NAME0..N` (`setbitmap:BP1aCell` + `animstartframe=5` → `BP1ACELL1..5`).
Of 74 names referenced from `WND.DLL`, 66 resolve (17 exact, 49 as frame prefixes); the
missing ones are `Mask`, `BorderPrinceMask`, `BattleMapBorder*`, `SampleJourBook`, `Tent4`
(masks are probably generated by the code). 179 bitmaps are not referenced from `WND.DLL`
(portraits, book pages, buttons) — those are drawn directly by the code.

### Palettes

- Index 0 is almost always **(0,0,255) blue = colour key** (background of portraits,
  cells, `FANCYLETTERS`). Indices 1–9 are usually padding magenta (255,0,255), 246–255 match
  `SYS.PAL`.
- The UI palettes in `BINARY/GLUE/` split the 236 free Windows indices in two:
  **`GLUE<X>.PAL` = indices 10–105** (96 entries, 384 B) and **`WIND<X>.PAL` = 106–245**
  (140 entries, 560 B) — confirmed sequential in all 19 files.
- The embedded palette of a screen equals such a pair **exactly** (96/96 + 140/140):
  `CARAVAN` group (42 bitmaps) = `GLUECAR`+`WINDCAR`, `TITLESCREEN` = `GLUETITL`+`WINDTITL`,
  `MINDSCAPELOGO` = `GLUEMIND`+`WINDMIND`, `ENDSCREEN` = `GLUEEND`+`WINDEND`,
  `*MAGICPIC`/item pics = `GLUEBOOK`+`WINDBOOK`, 33 unit pics = `GLUEBK2`+`WINDBK2`,
  `FRAME*` = `GLUEMAP`+`WINDMAP`. The 511 map cells match `GLUEMAP` in 10–105 but only 128/140
  in 106–245 (they only use the low half).
- **Hypothesis:** at run time the game realizes one `GLUE`+`WIND` pair per screen
  (`[POSITION] set:palindex=N` in window scripts: `2` for `MAP`, `3` for `CARAVAN`), so a
  bitmap's own palette is an authoring copy. Rendering with the embedded palette is correct
  for every image viewed. Some screens (`OPTIONSCREEN`, `GAMESTARTSCREEN`, `DEADSCREEN`,
  26 creature pics such as `SKAVENPIC`) match no `.PAL` file — they probably bring their own palette.

## `RT_STRING` — ID organisation

Standard Win32 layout: block N holds IDs `(N−1)×16 … +15`, each string u16 length + UTF-16LE.

**`GMTXT` (battle)** — text markup `@@(fN)` = font N, `@@(cN)` = colour N, `_` = space
(names of spells/items use `_`, same convention as `<`/`_` in `.BTS`).

| IDs | Content |
|---|---|
| 162–164 | `WARHAMMER`, `OK`, `CANCEL` |
| 1000–1007 | battle status: Deploy your regiments, Game paused, Mission complete, "%s: We must retreat!" |
| 2000–2021 | combat log: missiles, range/line of sight, spell dispelled, artillery misfire |
| 30000–30028 | spells (`ID_SP_MS_*` casting modes, then Wind Blast … Madness) |
| 31000–31016 | magic items (same names as `addmagicitem:` identifiers) |
| 32000–32008 | profile abbreviations M WS BS S T W I A Ld |
| **33000–33034** | **mission objective captions**, see 1.8 below |
| 34000–34401 | regiment shouts by race (34000 greenskins, 34100 humans, 34200 dwarfs, 34300 skaven, 34400 monsters) |
| 36000–36070 | render/sound option toggles (used by the options screen via `set:res=`) |

**`BRTXT` (briefing / campaign)**

| IDs | Content |
|---|---|
| 100–113 | armour ratings; 150–162 caravan hotspot hints ("Click here to view Troop Roster."); 200–232 weapons |
| 300–341 | UI words (Next, Hire, Fire, Attack!, the 256-colour warning) |
| 400–402 | troop selection titles |
| 500–507 | campaign chapters: Border Princes, Revenge, Black Mountains, Worlds Edge Mountains, Zhufbar, Nuln, Grey Mountains, Loren |
| **601–691** | **mission names**, `6RN`: R = chapter-ish group (0 Border Princes, 2 Revenge, 3 Black Mountains, 4–5 Worlds Edge, 6 Zhufbar, 7 Nuln, 8 Loren, 9 final) |
| 700–725 | profile names (Movement (M)…) |
| 800–870 | map labels: regions, cities, places |
| 900–988 | encounter dialogue lines ("We are being ambushed!", Holger, Azguz, Allor…) |
| **1010–45010** | **briefing dialogue**, `B×1000 + 10k + j`: one speech turn per `+10`, continuation lines `+1,+2…` (`7010..7016` Dietrich, `7020..7021` Commander). Played by `playtext:res=`/`queuetoplaytext:res=` in `WND` briefing scripts |
| 9500–9614 | short voice-line labels (Fire!, Charge!, Waarrggh!, Fart) — probably subtitles of `GLUE/SPEECH` WAVs (ROADMAP 3.4) |

**`BKTXT` (books)**: 100–128 races; 200–202 magic colleges; 250–266 magic items;
300–334 named regiments of the roster; 400–613 debriefing/roster UI; **1000–1025 failure
lines, 2000–2025 success lines per objective letter** (1.8); 5000–5042 balance sheet
(Initial/Completion Payment, "Skaven killed bonus", "Villagers killed penalty"); 9000–9143 credits;
10000–10148 mission-specific debriefing sentences.

**`ANTXT` (cut-scene subtitles)**: `M×1000 + k`, M = movie number: `playmovie:A<M>` is always
preceded by `loadanimstringintocache:<M>0xx` (31/32 pairs; the exception `GMMISSION3` caches
18xxx and 19xxx before branching to `A18`/`A18B`). `+10,+20…` = speech lines, `+100,+101…` =
narration captions, `+510` = alternative version (`A12b`, `A16b`).

## `RT_RCDATA`

- **`BKTXT`**: 79 plain-text encyclopedia entries `<NAME>TEXT` (latin-1, terminated with
  `ESC CR LF`). 72 have a matching portrait `<NAME>PIC` in `BITMAP.DLL`.
- **`WND`**: 535 text scripts (latin-1, CRLF, `ESC`/`EOF` at the end, comments `;` and
  sometimes `//`). The original file names appear in comments (`File: mbp1.wnd`, `sbp1.run`)
  and in `script:armybook.wnd`, so each resource was a `.wnd` (window) or `.run` (script)
  file. **This is the "glue" language** listed as unknown in FORMATS.md (`testobjective`,
  `debrief`, `playmidi`, `unitjoinmission`…). Same syntax family as `.BTS`: `[SECTION]…[END]`,
  `command:argument`, `set:key=value`.

  | Section | Meaning |
  |---|---|
  | `[WINDOW]` | a screen or sub-window; contains `[POSITION]` (`x,y,vx,vy`, `palindex`), `[BITMAP]` (`setbitmap`, `setmask`, `animstartframe/animstopframe/timecnt`), `[TEXT]` (`set:res=` string ID, `font`, `format`, `settextcolor`), `[HOTSPOT]` (`set:res=` hint string, `cursor:`/`altcursor:` = cursor names from `WHSHR.EXE`, `script:`/`res:` = window to open), `[ANIM]` (talking portrait: `name:`, `set:sequence/frame/index/bkindex/controlpanel`), `[INCLUDE]` (`script:<resource>`), `[MISSIONWINDOW]`/`[MISSION]`, `[MIDI]`, `[DEMODEFAULT]` |
  | `[RUN]` / `[START]` | a script: `openwindow`, `opensubwindow`, `setcurwindow`, `addanimobject`, `applyseq`, `playtext`/`queuetoplaytext`, `playmidi`/`stopmidi`, `playmovie`, `playgame*`/`encounterplaygame*`, `setbattlescript`, `setdebrief`, `debrief*`, `addtroop`, `unitjoinmission`/`unitleavemission`, `gosub`/`goto`/`iftrue*`/`iffalse*`, `testobjective`, `gocaravan`, `autosave`, `enablebook` |

  Name prefixes = campaign chapter: `BP` Border Princes, `RE` Revenge, `BM` Black Mountains,
  `WE` Worlds Edge Mountains, `SZ` (siege of) Zhufbar, `EN` Empire/Nuln, `GM` Grey Mountains,
  `L`/`LM` Loren/last mission, `AM` final briefing, `GF` Gotrek/Mole machine. Kinds:
  `*BRIEF*` (briefing on the map with dialogue), `*MISSION*` (runs the battle), `MISSION*WINDOW`
  (mission choice), `FLOWSCRIPT*` (chapter flow), `MAPWINDOW*`, `TRAIL*`/`FLOWTRAIL*` (route
  animation), `MARK*` (map marker), `*WINDOW` (character portrait windows).

  A `[MISSION]` block ties everything together, e.g. `MISSIONBP01WINDOW`:
  ```
  [MISSION]
      set:res=601                 mission name: BRTXT 601 "Protect Schnappleburg"
      script:bpbr1.run            original file name of the briefing
      res:BPBrief1                briefing script (texts BRTXT 7010..7021)
      setbattlescript:bf003       battle FILE/SCRIPT/BF003.BTS
      setmissionscript:BPMission1 script that runs the battle (encounterplaygamewithdebrief:bf003)
      cash:1,100,400,50,25,A      see hypotheses below
  [END]
  ```

## ROADMAP 1.8 — `Objective:L,a,b`

**Letter (✅, strong).** With `i = L − 'A'`:
- `GMTXT 33000 + i` = objective caption shown in battle ("Your mission objectives are...");
- `BKTXT 1001 + i` = failure line, `BKTXT 2001 + i` = success line in the debriefing.

| Letter | GMTXT caption | BKTXT fail / success | Battles | Consistent with briefing? |
|---|---|---|---|---|
| A | Eliminate the enemy | did not completely crush / killed or routed all | 47 battles | generic |
| B | `A_MASTER` | saved %d%% of the villagers / saved %d villagers | BF003, BF004_x, BF011, BF028, BF036 | BF003 = Protect Schnappleburg (villagers) |
| C | `C_MASTER` | %d Buildings destroyed / buildings undamaged | BF003, BF004_x, BF033, BF035 | BF003 protects buildings |
| D | Protect the wagons | We lost %d wagons / saved %d wagons | BF005, BF006 | Escort to Holst, `BPMISSION2` runs `testobjective:D` |
| E | Leave no survivors | Only %d%% killed / slaughtered %d%% | BF007, BF025 | Patrol (paid per Skaven head); `BPMISSION5` `testobjective:E` |
| G/H | Inside the gates! / Silent Doors Shut | — | BF015, BF017 | Grumm's Gate, Listening Gate |
| I | Ambush. | — | BF026, BF029–031, BF042 | ambush battles |
| N | Get past the Dragon | — | BF014 | Khaz Drakk (dragon hall) |
| O | Capture Guy Gourard | — | BF009 | Capture Guy Gourard |
| Q | Protect the forest | — | BF024 | Poisoned Wind (debrief "Trees destroyed") |
| S | Capture Hiln. | We have failed to capture Hiln / captured Hiln | BF001 | Sven Carlsson mission (capture Otto Hiln) |
| T | Rescue Ilmarin. | failed to rescue / rescued Illmarin | BF010 | Rescue Ilmarin |
| U | Silent The Mission is Impossible. | We did not stand a chance sire | BF012, BF018, BF019 | Black Mountains missions whose debriefs say "abandon this route" |
| W | Destroy the enemy artillery. | — | BF017, BF027 | Listening Gate (strike on Orc artillery), Counter Attack (Holger's stone throwers) |
| Z | Silent Stay alive! | — | 50 battles | generic loss condition |
| K, X | Silent.Get a unit to secret area | — | 14 / 4 | ✅ confirmed: reach a target node and collect a named item there (`game_rules.md`) |
| V, Y, F, P, R, J, L | Count Dead Race / If Z then Fail Critical / Silent 'A' / `P_MASTER` / placeholders "Objective R/J/L" | — | few | see `game_rules.md`: F is a standalone copy of A's "eliminate the enemy" logic; P is a "keep a named unit alive" check; V computes a race-kill tally for the debrief only (always reads "met"); R, L are inert stubs; J is a post-decision cleanup step; Y mirrors a shared flag |

"Silent" captions are apparently hidden from the player. GMTXT 33026–33034 (Protect the
villagers, Rescue the slaves, …, Free the prisoners) lie past `Z` and are probably substituted
by the mission DLL for the `*_MASTER` letters.

**Evaluator logic for every letter** (what each one actually counts/checks, the `a`/`b` mechanism, and which
letters can end the battle) is now public: `notes/game_rules.md` §"Missions and objectives".

**Numbers `a,b` (🟡).** Checked on all 54 `.BTS` with `pe_missions.py --check`:
- `A,a,b`: `a` = total men (`s_side[1]` sum) and `b` = number of **enemy** regiments (`s_side[0]` bit 7) in **39/47**; `b` alone 41/47.
- `Z,a,b`: `a,b` = men and regiments of the **player army** (`loadmerc` `.MRC`) in **40/50**. Misses are
  battles where the player gets NPC allies or reinforcements (BF015/017: 18 = 4 player + 14 NPC
  regiments), test files and `Z,0,0`.
- `B,a,b`: `b` = NPC men (villagers) in 9/11; `a` = 80/61/10/0 — probably a % threshold.
- `D,0,3`: `b` = NPC regiments (the 3 wagons) 2/2. `E,100,69`/`F,72,4`: enemy men.
- Interpretation: the mission editor wrote a snapshot of the counts when saving; later edits of
  the unit lists were not always re-saved. Semantics of `a,b` for K/X/R/I/P/V are unknown
  (K/X pairs like `K,13,3 X,14,7`, `K,24,4 X,25,7` look like consecutive indices).

**Mission `cash:` (hypothesis):** `cash:type,initial,completion,per_unit,penalty,letters…`.
Supported by briefings: Vanberg `8,500,1000` ("an advance plus … 1000 crowns"), Counter Attack
`9,0,1000,…` ("1000 gold crowns"), Patrol `4,200,200,20,0` ("20 crowns a head"), Rat Trap
`11,0,500,25,0` ("25 crowns per man"). The trailing letters are objective letters: `O` for
Capture Guy Gourard, `A,Q` for Poisoned Wind (Q = Protect the forest); `M` marks march-only
missions with no fee. BKTXT 5000–5024 are the matching balance-sheet line labels.

## How it was verified

- Parser: `pe_resources.py --summary` on all 9 PE files; `pe_extract.py --all` extracts all
  1669 resources without an exception; bitmap sizes = header + palette + padded rows for all 717.
- Visually (Read of the PNGs): `TITLESCREEN`, `CARAVAN`, `MAP`, `ARMYBOOK`, `OPTIONSCREEN`,
  `DEADSCREEN`, `GAMEENDSCREENSUCCESS`, `BATTLEMAP0`, `SKAVENPIC`, `CERIDANPIC`,
  `SWOGRUDGEBRINGERPIC`, `DIETBOOKCELL0`, `FANCYLETTERS`, `BP3CELL1`, a cursor from `WHSHR.EXE`.
  All look like correct 1995 UI art with correct colours and orientation.
- Palettes: per-index-range comparison of all 29 distinct embedded palettes with every RGB `.PAL`.
- Strings: all numeric `set:res=`/`playtext:res=` references in `WND` (442 IDs) exist in
  `BRTXT`, except 36000–36060 which are in `GMTXT` (options screen) and `-1`/`-2` (no text).
  `loadanimstringintocache` IDs match the following `playmovie` number in 31/32 cases.
- Objectives: semantic match of caption/debrief text with the briefing of the mission that runs
  the battle (table above), plus the count test (`--check`).


`parse_dialog`, `parse_menu`; `pe_missions.mission_blocks`, `glue_lines`, `battle_objectives`.
